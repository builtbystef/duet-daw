# 0002 — The Collaborator perceives the project through deterministic tools, never audio

Context: no LLM vendor claims musical reasoning over audio, and the one API that accepts audio downsamples it to 16 kbps mono — while every musical fact worth having is either in the project data model or measurable by DSP. Decision: the Collaborator receives only structured text from a closed set of read-only tools, each value carrying its provenance (read, measured, or estimated-and-wrapped); it never receives rendered audio. Reason: a tool that measures is right every time and cheap to test, a model asked to listen is unverifiable — and the fod077 prototype showed frontier models act on the measured numbers at a level a producer would accept (7/7 and 6/7 across mix, arrangement, and harmony fixtures).
