# Architecture

The modules of this system, and the seams between them. Update this file when the shape changes. Audits compare it with reality.

Duet DAW is a native desktop digital audio workstation, written in C++, built to make collaboration between a music producer and an AI easy.

No modules exist yet. Intended, but not yet decided (each choice deserves an ADR when it lands):

- **Audio engine** — playback, recording, and processing.
- **GUI** — the desktop interface; framework undetermined.
- **AI integration** — the seam through which the AI participates in a session.
- **Build system** — undetermined.
