# Contributing

Duet DAW does not accept outside code contributions (pull requests) at this time. The project keeps the option of a closed commercial edition open, which requires the maintainer to hold relicensing rights over every line of code; accepting contributions without a CLA would permanently foreclose that, and running a CLA is overhead the project does not want yet. The reasoning is recorded in [docs/adr/0001-agplv3-no-outside-contributions.md](docs/adr/0001-agplv3-no-outside-contributions.md).

**Bug reports, feature requests, and discussion are welcome** — please open an issue.

If this policy changes, contributions will require a Contributor License Agreement, and this file will say so.
